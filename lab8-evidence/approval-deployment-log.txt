## 7. Database Backup and Recovery Explanation

Application rollback and database recovery are separate operations.

Application rollback restores a previously working application artifact. It does not automatically reverse database migrations or restore deleted or modified records.

Database recovery requires a separately planned database backup and restoration procedure.
